# ASSAULT FRAME VS

アーケードのバーサス系 3D 対戦アクション（2機のロボットが射撃と格闘で撃ち合うタイプ）。ブラウザで動き、スマホのタッチ操作に対応。

**▶ 遊ぶ: https://yutianqiao7-dev.github.io/assault-frame-vs/**
（スマホのブラウザでそのまま動きます。ダウンロード不要）

現状は **1 vs 1 vs CPU（トレーニング）** まで。

```bash
npm install
npm run dev
```

`http://localhost:5174` を開く。`server.host = true` なので、同じ Wi-Fi のスマホから `http://<PCのIP>:5174` でも遊べる。

## 操作

| 操作 | キーボード | スマホ |
|---|---|---|
| 移動 | WASD / 方向キー | 左バーチャルスティック |
| ブースト（地上滑走・上昇・空中移動） | L または Space（**押しっぱなし**） | ジャンプ |
| ステップ（回避・行動キャンセル） | Shift | ステップ |
| 射撃 | J（押しっぱなしで連射） | 射撃 |
| 格闘 | K（当たった直後にもう一度で連撃） | 格闘 |
| サブ射撃 | U | サブ |
| 特殊射撃 | I | 特射 |
| 特殊格闘 | O | 特格 |
| 覚醒 | Q | 右上の覚醒ボタン |

移動は**常に敵基準**。スティック上＝敵に接近、下＝離脱、左右＝敵を軸に横移動。

### 立ち回りの骨格

- **地上ブーストダッシュ**：地上でブースト＋方向を入れると、浮かずに地面を滑走する（速度 27 / 歩き 12）。押し続けて 0.5 秒経つとそのまま上昇に移行する。方向を入れずにブーストだけ押すと真上に上がる。
- ブーストボタンは**押しっぱなしで飛ぶ**。離すと落ちる。
- **着地するとブーストが全回復**するが、着地硬直が出る。この硬直を狙う／狙われるのがこのジャンルの核。着地すると地上ダッシュ枠もリセットされるので、**着地→即ブーストでまた地面を滑れる**。
- ブーストを使い切ると**オーバーヒート**。空中なら強制落下＋着地硬直（1.15秒）、地上ならその場で同じだけ硬直する。
- **ステップは行動をキャンセルできる**（射撃硬直・格闘の振りをキャンセル）。ブーストを固定量消費する。
- **格闘もブーストを食う**。踏み込みに固定コスト（`meleeCost` 14）＋突進と振りの間は毎秒消費が続く。N格1段で約 30、3段フルコンボで約 61。ブーストが足りない／オーバーヒート中は格闘を出せないので、**コンボを完走すると着地を晒すことになる**。
- 先行入力バッファ（0.35秒）があるので、硬直中に押しても受け付ける。

## 実装済みのシステム

- **ブースト / 地上ブーストダッシュ / ステップ / 着地硬直 / オーバーヒート**
- **ロックオン**：常に敵を向く。カメラは自機の後方から敵を含めて捉える。
- **武装**：弾数・リロード・クールタイム・偏差射撃・誘導。ビーム／実弾／砲弾（放物線・爆風）。
- **格闘**：接近（ラッシュ）→ 3 段連撃。段ごとにダメージ・ダウン値・吹き飛ばしが違う。踏み込みと突進・振りでブーストを消費する。
- **ダウン値**：合計 5.0 で強制ダウン。1.6 秒被弾しないとリセット。
- **コンボ補正**：ヒット数に応じて 1.0 → 0.85 → 0.74 …（`COMBO_SCALE`）
- **覚醒**：与ダメ・被ダメでゲージが溜まる。発動でブースト全回復＋移動 1.22 倍・与ダメ 1.13 倍を 9 秒。
- **戦力ゲージ（コスト）**：両陣営 6000。撃墜されると機体コスト（2000）を引かれる。0 で敗北。
- **CPU**：EASY / NORMAL / HARD。距離取り・横移動・被弾回避のステップ・格闘・覚醒。難易度で反応速度と**射撃精度**（`aimError`）が変わる。

## ファイル構成

```
src/
  config.js     機体データと全チューニング定数（ここを触ると挙動が変わる）
  main.js       レンダラ・ゲームループ・勝敗・タイトル/リザルト
  mech.js       機体のステートマシン（移動/攻撃/被弾/ダウン/覚醒/ポーズ）
  mechmodel.js  機体のプロシージャルモデル
  combat.js     弾と命中判定、エフェクト
  ai.js         CPU の思考
  camera.js     ロックオンカメラ
  input.js      キーボード + バーチャルスティック
  hud.js        HUD の DOM 更新
  arena.js      ステージ・ライティング
  style.css     HUD とタッチ UI
```

チューニングはほぼ全部 `src/config.js` に集約してある。

### デプロイ

`main` がソース、`gh-pages` がビルド済みサイト。更新するときは:

```bash
npm run build
```

そのあと `dist` を `gh-pages` ブランチに force push する（`vite.config.js` の `base` が `/assault-frame-vs/` を付けるので、そのままのパスで動く）。

## 開発メモ

- `window.__dbg` にゲーム内部を出している。
  - `__dbg.step(dt)` … 1 フレーム進めて描画（rAF が止まっていても手動で進められる）
  - `__dbg.sim(n)` … 描画せず n フレーム進める（対戦のシミュレーションに使う）
  - `__dbg.game` / `__dbg.world` / `__dbg.chase` …
- 開発サーバーに `POST /__shot/<name>` がある。base64 の JPEG を投げると `.shots/<name>.jpg` に保存する（プレビューが見えない環境でのレンダリング確認用）。
- `preserveDrawingBuffer` と `window.__dbg` は `import.meta.env.DEV` で囲ってあるので、本番ビルドには入らない。

## クレジット / 権利について

機体名・武装名・タイトルはすべてオリジナル。3D モデル・コード・UI もすべてこのリポジトリ内で自作（外部アセットの取り込みなし）。依存は three.js と Vite のみ。

ジャンルとしてアーケードのバーサス系 3D 対戦アクションを参考にしているが、特定作品の名称・意匠・アセットは使用していない。
